# 浪漫邮轮之旅 · Claude Code 插件

为情侣和新婚夫妇提供的浪漫邮轮选择，适合在特别的日子里享受浪漫与美好。

![published with craftwave](https://img.shields.io/badge/published%20with-craftwave-6366f1)

## 安装

在 Claude Code 中执行：

```
/plugin marketplace add OWNER/craftwave-skill-10-claude-plugin
/plugin install craftwave-skill-10@craftwave-skill-10-marketplace
```

> 将 `OWNER` 替换为本仓库所属的 GitHub 账号/组织名。

安装后即可在 Claude Code 里使用技能 **浪漫邮轮之旅**。本仓库由
[CruiseSkillBridge](https://cruiseskillbridge.com) 按 Claude Code 插件市场规范自动生成。
